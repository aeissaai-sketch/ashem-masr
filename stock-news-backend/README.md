# 📊 Stock News API - البورصة المصرية

خادم وسيط لجلب وتحليل أخبار البورصة المصرية.

## 🚀 التشغيل

```bash
# تثبيت الاعتماديات
npm install

# تشغيل في وضع التطوير
npm run dev

# تشغيل للإنتاج
npm start
```

## 📡 نقاط النهاية (Endpoints)

| الطريقة | المسار | الوصف |
|---------|--------|--------|
| GET | /api/stocks | الحصول على جميع الأسهم مع أخبارها |
| GET | /api/stocks/:symbol | الحصول على سهم واحد |
| GET | /api/stocks/search?query= | البحث عن أسهم |
| GET | /health | فحص صحة الخادم |

## 📦 التقنيات المستخدمة

- Node.js + Express
- Axios (لجلب البيانات)
- Cheerio (لتحليل HTML)
- CORS (للسماح بالاتصال)
- Dotenv (للمتغيرات البيئية)
